# TypeSense

### An Adaptive Typing Tutor Based on Typing Behavior and Finger Analysis

TypeSense is a typing tutor designed to go beyond basic typing speed and
accuracy. The system analyses typing behaviour such as hesitation,
corrections, repeated errors, and difficult key transitions to identify
individual learner weaknesses.

Where reliable, finger-level information from a standard webcam will also
be explored to determine whether physical finger behaviour can improve
personalization.

## Main Features

- Typing speed and accuracy measurement
- Keystroke and timing analysis
- Detection of repeated errors and difficult transitions
- Learner profile
- Personalized exercise selection
- Session history
- Optional webcam-based finger analysis
- Comparison of adaptive and fixed practice
